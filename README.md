# Renata Sacerdotisa — site moderno

Landing page responsiva em HTML, CSS e JavaScript, criada para converter visitantes do Instagram em conversas no WhatsApp.

## Antes de publicar
Abra `script.js` e troque:
`const WHATSAPP_NUMBER = "5500000000000";`

Use DDI + DDD, sem espaços, parênteses ou símbolos.

O Instagram está configurado como `@renatasacerdotisa`.

## Estrutura
- `index.html` — página completa
- `style.css` — identidade visual e responsividade
- `script.js` — WhatsApp e menu mobile
- `assets/` — imagens enviadas nesta conversa

## Publicação
Pode ser publicado no GitHub Pages, Netlify, Vercel ou hospedagem tradicional.
